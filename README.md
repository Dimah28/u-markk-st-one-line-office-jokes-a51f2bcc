Entry for the [One-Line Office Jokes](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc) bounty on make.fun.

`main.py` (Python 3.13, stdlib-only, deterministic, no network) writes one
original single-line office joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` and
validates the competition gate (UTF-8, 1–199 characters, one line, not only
whitespace) before writing.

## The joke

> The printer only jams on the page I actually need, so now I print the wrong page first as a decoy.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
